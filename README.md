# Antique · Rōsner · Zona

Stranica je napravljena u čistom HTML-u, CSS-u i JavaScriptu.

## Pokretanje

Dvaput klikni na `index.html`.

Nema instalacije, terminala, Nodea, `node_modules` mape ni buildanja.

## Glavne datoteke

```text
index.html       početna stranica
antiquebar.html  Antique Bar
rosner.html      Rōsner Lounge Bar
zona.html        Zona Lounge Bar
styles.css       kompletan dizajn i responsive pravila
script.js        menu, galerija, animacije i prijelazi
assets/          optimizirane slike, logotipi, fontovi i ikona
```

Originalne fotografije ostavljene su netaknute u tri izvorne mape.
